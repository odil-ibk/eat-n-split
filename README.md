# Eat-n-Split 🍽️

A bill-splitting app built with React while following a React course on Udemy. Add friends, pick one, and split a bill to see who owes whom.

## Features

- View a list of friends with their balances
- Add a new friend
- Select a friend and split a bill with them
- Choose who pays the bill (you or your friend)
- Balances update automatically:
  - 🔴 you owe your friend
  - 🟢 your friend owes you
  - ⚪ you're even

## What I practiced

- Building and nesting components
- Passing data with props
- Managing state with `useState`
- Lifting state up
- Controlled form inputs
- Conditional rendering
- Rendering lists with `map()`
- Reusing components with the `children` prop

## Tech stack

- React
- JavaScript (ES6+)
- CSS

## Run locally

```bash
git clone https://github.com/odil-ibk/eat-n-split.git
cd eat-n-split
npm install
npm start
```

If the project uses Vite, run `npm run dev` instead of `npm start`.
